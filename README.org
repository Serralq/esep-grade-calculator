* ESEP Grade Calculator

This library is a simple utility to calculate your grades.

Runtime requirements:
Golang 1.24+

* Unit tests
Run unit tests:
```
cd grade_calculator/
go test ./...
```

Run unit tests with code coverage:
```
cd grade_calculator/
go test -coverprofile=coverage.txt ./...
```

* File structure
| ./grade-calculator/go.mod                   | library settings |
| ./grade-calculator/grade_calculator.go      | code             |
| ./grade-calculator/grade_calculator_test.go | tests            |
